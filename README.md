## Evidence standards

I separate evidence from claims, coverage from probability, replay from causation, and model output from a
human decision. Synthetic data is labelled. Provider failures are visible. A demo is not described as a
production deployment, security audit, regulatory certification, or live integration unless the repository
contains evidence for that claim.
