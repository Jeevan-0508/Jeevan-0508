# Portfolio audit

Audit date: 2026-11-06  
Account: [Jeevan-0508](https://github.com/Jeevan-0508)  
Scope: 45 accessible repositories (42 public, 3 private, 6 archived).

This is a recruiter-facing documentation and evidence audit, not a claim that a repository is production-ready.
Scores are triage scores derived from the accessible README, repository tree, visible tests/workflows, documentation
links, onboarding commands, and demo references. A high score means the repository communicates its current
scope well; it does not mean that external adoption, security, regulatory compliance, or production maturity has
been proven.

## Scoring rubric

| Dimension | Weight |
| --- | ---: |
| Recruiter clarity and business relevance | 25 |
| Visual presentation and readability | 20 |
| Technical credibility and evidence | 20 |
| Architecture and implementation explanation | 15 |
| Demo accessibility and onboarding | 10 |
| Documentation quality and completeness | 10 |

The abbreviated columns below are \`C / V / T / A / D / O\` in the same order as the rubric, with each value
shown on its weighted scale. “Tests/CI” means a test/spec/workflow marker was present in the accessible tree;
it is not a fresh execution result.
